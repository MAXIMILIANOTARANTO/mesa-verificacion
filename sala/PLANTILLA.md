# Plantilla de caso

Copiar esta carpeta no: crear `sala/casos/AAAA-MM-DD_slug/` con estos tres archivos.

## `enunciado.md`

```markdown
# título

- hipótesis: el archivo de `hipotesis/` que se está examinando
- enunciado:
- la haría falsa:
- colega del primer turno:
- estado: abierta
```

## `turno-01.md`

```markdown
# turno 01 — nombre del colega

- colega:
- path del skill, o «hueco»:
- qué miró:
- qué encontró:
- qué queda sin mirar:
```

## `cierre.md`

Se escribe solo al final. Una línea, y el enlace al archivo de `falseamientos/` o `verificaciones/`.

```markdown
# cierre

- resultado: falseada | verificada | detenida por hueco
- archivo: 
```
